Installation generale

Cote Amiga

Copiez les programmes dans un tiroir, par exemple: 

SYS:Tools/3DToolbox/

Vous pouvez aussi creer un assign: 

Assign 3dtoolbox: SYS:Tools/3DToolbox

Programmes principaux: 

Print3DToolboxMUI
OctoControlSpeak
OctoControlSpeak_EN
SlicerMUI
Text2STLMUI
GCodeColorPauseMUI
ZSetupMUI
ZSetup
PiTempMUI
DDD2STLMUI
3DView

Configurations dans S:

S:octocontrol_native.cfg
S:octocontrol_speech.cfg
S:pitemp.cfg
S:zsetup.cfg
S:slicermui.cfg

Distribuez seulement les fichiers exemple. Ne distribuez jamais un fichier contenant votre vraie cle API OctoPrint.

Librairies utiles

muimaster.library
bsdsocket.library
ddd.library
reqtools.library
narrator.device et translator.library pour la parole

La pile TCP/IP Amiga doit etre active pour OctoControlSpeak, SlicerMUI, PiTempMUI et ZSetupMUI.

Cote PC

Pour SlicerMUI, installez Python 3 et PrusaSlicer. Le script slicer_server.py tourne sur le PC et appelle prusa-slicer-console.exe.

Cote OctoPrint

OctoPrint doit etre accessible sur le reseau local. L'imprimante doit etre connectee dans OctoPrint. OctoControlSpeak utilise une cle API OctoPrint.
