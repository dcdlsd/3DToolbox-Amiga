Installation generale

Cote Amiga

Le plus simple est d'utiliser le script Install fourni a la racine de l'archive. Il demande l'emplacement, cree le tiroir 3DToolbox, copie les outils, les docs et les fichiers PC/Pi, puis peut creer l'assign 3DToolbox:.

Exemple d'installation: 

SYS:Tools/3DToolbox/

Vous pouvez aussi creer un assign: 

Assign 3dtoolbox: SYS:Tools/3DToolbox

L'installateur cree cet assign dans S:3DToolbox-startup et active l'assign pour la session courante.

Par securite, il ne modifie pas S:User-startup directement. Pour rendre l'assign permanent apres redemarrage, ajoutez manuellement cette ligne: 

Execute S:3DToolbox-startup

Sources

Pendant l'installation, vous pouvez choisir d'installer ou non le tiroir SOURCE. Il contient les sources AmigaE et les modules utiles, dont bsdsocket.m et les modules lies a ddd.library.

Programmes principaux: 

Print3DToolboxMUI
OctoControlSpeak
OctoControlSpeak_EN
SlicerMUI
Text2STLMUI
GCodeColorPauseMUI
ZSetupMUI
ZSetup
PiTempMUI
DDD2STLMUI
3DView

Configurations dans S:

S:octocontrol_native.cfg
S:octocontrol_speech.cfg
S:pitemp.cfg
S:zsetup.cfg
S:slicermui.cfg

Distribuez seulement les fichiers exemple. Ne distribuez jamais un fichier contenant votre vraie cle API OctoPrint.

Librairies utiles

muimaster.library
bsdsocket.library
ddd.library
reqtools.library
narrator.device et translator.library pour la parole

La pile TCP/IP Amiga doit etre active pour OctoControlSpeak, SlicerMUI, PiTempMUI et ZSetupMUI.

Cote PC

Pour SlicerMUI, installez Python 3 et PrusaSlicer. Le script slicer_server.py tourne sur le PC et appelle prusa-slicer-console.exe. Les fichiers et explications sont copies dans: 

3DToolbox:PC_SlicerServer/

Cote Pi / Linux

Pour PiTempMUI, copiez le script pitemp_server.py sur le Raspberry Pi ou la machine Linux a surveiller, puis lancez-le avec Python 3. 

3DToolbox:PC_PiTempServer/

La pile TCP/IP doit etre active sur l'Amiga avant d'utiliser OctoControlSpeak, SlicerMUI, PiTempMUI ou ZSetupMUI.

Cote OctoPrint

OctoPrint doit etre accessible sur le reseau local. L'imprimante doit etre connectee dans OctoPrint. OctoControlSpeak utilise une cle API OctoPrint.
