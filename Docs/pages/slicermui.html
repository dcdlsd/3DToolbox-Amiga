SlicerMUI / Slicer Bridge

A quoi ca sert ?

SlicerMUI envoie un STL depuis l'Amiga vers un serveur Python sur PC. Le PC lance PrusaSlicer en ligne de commande, puis l'Amiga recupere le G-code. 

Amiga STL -> PC SlicerServer -> PrusaSlicer -> G-code -> Amiga

Configuration PC

slicer_server.py
slicer_server.cfg
Python 3
PrusaSlicer
prusa-slicer-console.exe
profil imprimante .ini

Exemple de slicer_server.cfg: 

HOST=0.0.0.0
PORT=18090
ALLOWED_CLIENTS=127.0.0.1,IP_DE_VOTRE_AMIGA
MAX_UPLOAD_MB=64
ALLOW_PC_PATHS=no
PRUSA_EXE=C:\Program Files\Prusa3D\PrusaSlicer\prusa-slicer-console.exe
BASE_DIR=C:\SlicerBridge
PROFILE_STANDARD=C:\Users\Denis\AppData\Roaming\PrusaSlicer\MonProfil.ini

Remplacez IP_DE_VOTRE_AMIGA par l'adresse IP reelle de votre Amiga. Remplacez le profil .ini par le profil de votre imprimante.

Champs de SlicerMUI

IP addressAdresse IP du PC qui lance slicer_server.py.
PortPort du serveur, 18090 par defaut.
Local STLFichier STL present sur l'Amiga.
PC STL nameNom sous lequel le STL sera stocke cote PC.
Scale %Echelle appliquee avant slicing.
G-code outputChemin du G-code a recuperer sur l'Amiga.
Job IDNumero de travail cote serveur PC.

Boutons

TestVerifie que le serveur PC repond.
SaveSauve IP et port dans S:slicermui.cfg.
STL InfoEnvoie le STL pour lire dimensions et scale conseille.
Upload+SliceEnvoie le STL et lance PrusaSlicer cote PC.
LastRelit le dernier job du serveur.
JobRelit le job ID indique.
DownloadRecupere le G-code genere.
FilesListe les STL/G-code connus du serveur.
DeleteEfface le fichier selectionne cote serveur.
ClearVide la zone information.

Workflow conseille

  1. Lancer slicer_server.py sur le PC.
  2. Tester la connexion dans SlicerMUI.
  3. Choisir un STL local.
  4. Cliquer STL Info et lire le scale conseille.
  5. Corriger le scale si necessaire.
  6. Cliquer Upload+Slice.
  7. Quand le job est OK, cliquer Download.
  8. Envoyer le G-code avec OctoControlSpeak.
