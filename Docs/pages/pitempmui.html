PiTempMUI

A quoi ca sert ?

PiTempMUI lit la temperature d'un Raspberry Pi depuis l'Amiga. C'est pratique pour surveiller un Pi qui fait tourner OctoPrint, surtout dans un boitier.

Cote Raspberry Pi

Lancez le petit serveur Python: 

python3 pitemp_server.py

Le serveur renvoie la temperature du Pi sur le reseau local.

Cote Amiga

IPAdresse du Raspberry Pi.
PortPort du serveur PiTemp.
ReadLit la temperature.
AutoRafraichissement automatique si active.

Une temperature elevee peut etre affichee en rouge selon le seuil prevu dans le programme.
