ZSetupMUI

A quoi ca sert ?

ZSetupMUI aide a regler le Z offset de l'imprimante depuis l'Amiga. Il utilise un petit programme de commande G-code nomme ZSetup.

Attention

Une mauvaise valeur Z peut faire taper la buse dans le plateau. Utilisez cet outil seulement si vous comprenez le reglage Z de votre machine. Restez pret a couper l'imprimante pendant les tests.

Commandes typiques

G28       Home
G29       Auto-level si supporte
M851      Lire/ecrire le Z offset Marlin
M500      Sauver en EEPROM

Conseils

  • Commencez proche de 0.00 pour la distribution.
  • Reglez par petits pas, par exemple 0.05 mm.
  • Utilisez une feuille de papier pour verifier la hauteur.
  • Apres sauvegarde, verifiez avec M503 si votre firmware le permet.
