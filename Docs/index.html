3DToolbox Amiga

3DToolbox regroupe plusieurs outils Amiga autour de l'impression 3D: OctoPrint, PrusaSlicer via serveur PC, fichiers STL, G-code, pause couleur, surveillance et reglage Z.

L'Amiga reste le poste de controle. Le PC ou le Raspberry Pi font seulement les taches trop modernes ou trop lourdes pour lui.

Menu cliquable
