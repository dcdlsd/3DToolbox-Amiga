General Installation

Amiga Drawer

The easiest method is to use the Install script included at the root of the archive. It asks for the destination, creates the 3DToolbox drawer, copies the tools, documentation and PC/Pi files, and can create the 3DToolbox: assign.

Example installation:

SYS:Tools/3DToolbox/

You can create an assign:

Assign 3dtoolbox: SYS:Tools/3DToolbox

This assign is useful because the toolbox launcher and icons expect the 3dtoolbox: path.

The installer stores this assign in S:3DToolbox-startup and activates it for the current session.

For safety, it does not modify S:User-startup directly. To make the assign permanent after reboot, manually add this line: 

Execute S:3DToolbox-startup

Never publish your real OctoPrint API key. Keep only example configuration files in public archives.

Sources

The SOURCE drawer contains the AmigaE source files for the distributed tools. SOURCE/modules contains useful AmigaE modules such as bsdsocket.m and the ddd modules. SOURCE/ddd_stl_patch contains the STL-related ddd.library source patch. The installer lets you choose whether this drawer should be installed.

PC and Pi Servers

PC_SlicerServer contains the Python server used by SlicerMUI and PrusaSlicer. Install Python 3 and PrusaSlicer on the PC, then configure slicer_server.cfg.

PC_PiTempServer contains the small Python server used by PiTempMUI on a Raspberry Pi or Linux machine. Copy pitemp_server.py there and run it with Python 3.

The Amiga TCP/IP stack must be online before using OctoControlSpeak, SlicerMUI, PiTempMUI or ZSetupMUI.

Requirements

  • AmigaOS 3.x compatible system
  • MUI
  • A TCP/IP stack such as Miami, AmiTCP or Roadshow
  • bsdsocket.library
  • OctoPrint reachable on the local network
  • Python 3 and PrusaSlicer on the PC for Slicer Bridge
