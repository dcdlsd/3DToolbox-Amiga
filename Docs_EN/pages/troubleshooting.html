Troubleshooting and Security

OctoControlSpeak Does Not Connect

  • Check OctoPrint IP address and port.
  • Check the OctoPrint API key.
  • Make sure the Amiga TCP/IP stack is online.
  • Check that the printer is connected inside OctoPrint.

SlicerServer Does Not Answer

  • Make sure slicer_server.py is running on the PC.
  • Check the IP address and port in SlicerMUI.
  • Check Windows firewall.
  • Check ALLOWED_CLIENTS in slicer_server.cfg.

Rejected Client

If the server reports a rejected client, add the Amiga IP address to ALLOWED_CLIENTS. 

ALLOWED_CLIENTS=127.0.0.1,IP_OF_YOUR_AMIGA

STL Too Large

  • Use STL Info.
  • Apply the suggested scale.
  • Check the bed size in the PrusaSlicer profile.

PrusaSlicer Fails

  • Check PRUSA_EXE.
  • Check PROFILE_STANDARD.
  • Test the profile directly in PrusaSlicer on the PC.

3DView Does Not Display an STL

  • Try with a simple ASCII STL first.
  • Large objects can be too slow or too heavy.
  • Repair bad geometry with a PC tool if needed.

Security

  • Never publish your real OctoPrint API key.
  • Do not expose slicer_server.py to the internet.
  • Keep ALLOWED_CLIENTS limited to your Amiga machines.
  • Always supervise the printer when testing new G-code.
