PiTempMUI

Purpose

PiTempMUI reads the temperature of a Raspberry Pi from the Amiga.

Principle

Raspberry Pi -> small Python server -> Amiga PiTempMUI

Pi Side

Copy the script from PC_PiTempServer to the Raspberry Pi, then run:

python3 pitemp_server.py

Amiga Side

Enter the Pi IP address and port, then click Read or use automatic refresh.

This is useful when OctoPrint runs on a Raspberry Pi in a small case, especially during long prints.
