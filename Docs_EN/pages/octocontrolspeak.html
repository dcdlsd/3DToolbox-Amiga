OctoControlSpeak

Purpose

OctoControlSpeak controls OctoPrint from an Amiga without a modern web browser. It sends commands to OctoPrint, and OctoPrint controls the 3D printer.

Configuration

S:octocontrol_native.cfg

OCTOPRINT=192.168.1.xxx:80
APIKEY=PASTE_YOUR_OCTOPRINT_API_KEY_HERE

The API key must be created or copied from OctoPrint with a modern browser. Never put your real API key in a public archive.

Connection Buttons

SaveSaves IP address, port and API key.
TestChecks that OctoPrint answers.
Connect printerAsks OctoPrint to reconnect the printer.
RAZStops heaters, lifts Z, moves X/Y away and disables motors.
MiniHides the main window and keeps the monitor visible.

Read Buttons

StatusReads printer state, temperatures and progress.
JobReads current print job information.
M105Temperature command, useful as a communication test.
FilesLists G-code files stored in OctoPrint.
Print selectedStarts the selected OctoPrint file.
DeleteDeletes the selected OctoPrint file.

The file list is intentionally limited to remain stable on classic Amiga systems. If partial list: too many files appears, remove old G-code files from OctoPrint or use shorter file names.

Print Buttons

UploadUploads a G-code file from the Amiga to OctoPrint.
Upload+PrintUploads the G-code and starts printing.
PausePauses the print.
ResumeResumes the print.
CancelCancels the print and runs a calm-down sequence.
EMERGENCY M112Firmware emergency stop. Use only for a real problem.

Machine Buttons

HomeHomes the printer.
Motors OFFDisables the motors.
PLAPLA preheat according to the configuration.
Heat OFFTurns heaters off.
Heat NozzleHeats the nozzle for filament handling.
Insert Fil.Inserts filament.
Retract Fil.Retracts filament.

Speech

Speech uses SAY, narrator.device and translator.library. Spoken sentences can be changed in S:octocontrol_speech.cfg or S:octocontrol_speech_en.cfg. If the speech system is not installed, the program remains usable.
