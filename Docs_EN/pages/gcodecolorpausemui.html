GCodeColorPauseMUI

Purpose

GCodeColorPauseMUI inserts a manual color-change pause into a G-code file.

Typical Use

  1. Generate or slice a G-code file.
  2. Select the source G-code.
  3. Choose the layer where the pause must be inserted.
  4. Write the output G-code.
  5. Send the new G-code with OctoControlSpeak.

Single Extruder

This tool is mainly for single-extruder printers. It pauses the print so the user can manually change filament, then resume.

Pause Sequence

The inserted sequence moves the nozzle away, waits for the user, then performs a small retract/reprime sequence to reduce filament blobs when resuming.

Output Name

By default, the generated name uses a short suffix: 

model.gcode -> model_color.gcode

This avoids very long names in the OctoPrint file list read from the Amiga.
