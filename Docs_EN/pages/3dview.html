3DView

Purpose

3DView is a classic Amiga 3D viewer based on the work of Andre Capus.

STL Support

The package includes a modified ddd.library with STL-related support. This lets 3DView display simple ASCII STL files and helps check objects before slicing.

Limits

Very large STL files can be slow on classic Amiga hardware. PiStorm / Emu68 is more comfortable for heavy objects. Binary STL is not the main target of this viewer workflow.

Credits

3DView and the original ddd.library work are credited to Andre Capus.
